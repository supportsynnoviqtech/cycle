Cancellation Rule

Specific upcoming interval cancellation

Cancelling an upcoming booking marks only that specific interval as cancelled, without affecting any other record.

Document Reference Check

Unique record references

Each completed record generates documents with a distinct reference ID and calculated total amount.

Data Model

Sample & personal record isolation

Sample rentals (SMP-1001 to SMP-1005) are stored separately from personal rider plans saved to local storage.

Calculation Engine

Consistent financial totals

Totals are derived via the shared PerfectBikeCalc.calculateRentalTotal helper, so the same rate always produces the same total everywhere.
